INNIE AI is a modular artificial intelligence system built from scratch by INNIE Group.
It is designed to grow over time, starting from a small nano network and evolving toward
a larger transformer-based language model. The system is organized into clear modules:
a tokenizer that turns text into numbers, an embedding layer that turns numbers into
vectors, a neural network that learns patterns in language, a memory system that keeps
track of conversations, and an API that connects the backend to a simple web chat interface.
Every part of INNIE AI is open source and does not depend on any closed source AI service.
This project belongs to INNIE Group, a diversified holdings company based in Warri, Delta State, Nigeria.
Learning happens gradually. Each training run adjusts the weights of the network a little
at a time, using examples from the datasets folder. As more data is added, the model's
understanding of language improves. The long term goal is for INNIE AI to become a
capable assistant that reflects the values and direction of its creator.
